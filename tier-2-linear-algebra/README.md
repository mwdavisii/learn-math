# Tier 2: Linear Algebra

## Goal

Vectors, dot products, and matrices as linear maps, enough to read θ ∈ ℝⁿ, θᵀx, and Δθ_S · Δθ_T.

**Status**: Skeleton. Sessions are written when you're ~2 sessions from finishing the previous tier.

## Reading

- 3Blue1Brown, *Essence of Linear Algebra* (video series, cited by video title).
- Deisenroth, Faisal, Ong, *Mathematics for Machine Learning* (MML), ch. 2–3.

If a section number doesn't match your copy, find it by title.
